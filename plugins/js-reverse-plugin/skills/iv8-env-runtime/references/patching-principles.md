# P3 · 补环境原则 —— 配/补时守什么

> 服务于 **P3 配环境 + 补漏 + 跑通**。来自 hexin-v 等实战，压成两个元价值 + 5 条正交原则。
> 一句话：**我们不搬整个浏览器，只做一件事——和真机保持一致。目标检测什么就补什么，没检测的一概不补。**

---

## 0. 造 / 配 / 补 三分（iv8 各包多少）

| 层 | 内容 | 谁干 |
|---|---|---|
| **造环境** | window/document/DOM/事件/canvas/webgl/crypto/timer 全套 API | **iv8 全包**，零手写 |
| **配环境** | 指纹值（UA/屏幕/canvas…）+ 字段间一致性 | **你**（iv8 给旋钮，值你给） |
| **补漏** | 自带但实现是空的 stub 窟窿 | **你**（跑崩才知，替换；判据见 `references/trap-blacklist.md`） |

体力活（手写 window/DOM）没了；脑力活（配真值、对齐真机）还是你的。实测佐证：同花顺 chameleon 零 API 补 token 算出、BOSS zhipin 读 1259 字段零补、抖音 bdms 只替换 1 个 stub。

---

## 1. 两个元价值（统领全篇）

- **一致**：凡要补的，一律照真机抄到**分辨不出**。基准 = js-reverse MCP 取到的真机值（它是处理过、过检测的真机环境，照抄不发明）。
- **最小**：边界 = **目标真读到的检测面**，不是"完整浏览器"。只补目标真读的，不复刻整个 window/DOM/BOM。给不存在的威胁上盔甲 = 过度工程。

---

## 2. 五条原则

| 轴 | 原则 | 一句话 |
|---|---|---|
| A 标准 | **1 一致性** | 凡补的都与真机一致（值/形态/undefined 三维度），基准 = MCP，产物逐字符验收 |
| B 发现 | **2 报错驱动** | 缺什么靠报错 + MCP 核对，不读源码枚举；**绝不吞异常** |
| C 节奏 | **3 逐个核对** | 一次只补那一处，先核对再写，可排查（慢就是快） |
| D 取舍 | **4 语义驱动** | 不机械、不过度；语义预判 + 对账定必要，行为类按链构造 |
| E 不侵入 | **5 原始 JS** | 加载原始未格式化 JS、零修改，hook 靠目标外新增 |

### 原则 1 一致性 —— 三维度 + 两个静默暗坑

一致分三维度：**值 / 形态 / undefined**，基准以 MCP 为准，最终以产物逐字符等价验收。

| 维度 | 含义 | 缺/错时 |
|---|---|---|
| **值** | 字符串/数字/结构（userAgent、plugins 列表） | 多数缺了**抛错** → 报错驱动能抓 ✅ |
| **形态** ⚠️ | `toString=[native code]`、属性在原型链哪层、descriptor、typeof、`'x' in obj` | **不抛错**，静默走错分支 → 暗坑 |
| **undefined** ⚠️ | 该有值 vs 本就没有 | **不抛错**，漏补静默 → 暗坑 |

- **暗坑一 形态**：默认最小不上来套盔甲；便宜的形态对齐补时顺手做（成员放真机所在原型层、给对 descriptor）；贵的盔甲（全局伪造 toString、Proxy 拦 Function.prototype.toString）只在对账证明"确实被查"那处才做。iv8 里用 `__iv8__.wrapNative(fn,name)` 做 `[native code]` 伪装。
- **暗坑二 undefined**：读到 undefined **绝不因"没崩"就放过**。两种 undefined 长得一样意义相反，唯一区分 = 真机核对：真机也 undefined → 合法保持；真机有值 → 照真机补（判据同 `references/trap-blacklist.md` §0）。

### 原则 2 报错驱动 —— 绝不吞异常

缺什么只靠"报错 + MCP 核对"闭环发现，**禁止 grep/读源码枚举要补的字段**（大量目标是 VMP/WASM，读不了）。前提是**绝不吞异常**：任何补环境代码不许 try/catch 把目标的错吞掉续跑——吞了则报错驱动失效、执行流带偏、制造"JS 跑完但产物没出"的假成功。唯一例外：最外层探针"记录 + 原样重抛"。

### 原则 3 逐个核对

一次只补报错指出的那一处，先在 MCP 核对过才写进 env。批量脑补一串相关属性 = 多变量同时引入，一个不符就无法二分是谁害的。预判 ≠ 现在就写（预判只进"待核对清单"）。慢就是快。

### 原则 4 语义驱动

补每个属性前先问语义意图。行为/采集类（鼠标/键盘/传感器/时间序列）顺链追问：产物是否依赖 → 需要什么数据 → 怎么构造 → 怎么注入。用语义预判可能性、用对账定必要性，既不机械漏补也不过度构造。iv8 侧注入靠 `__iv8__.input.dispatchMouseEvent/dispatchPointerEvent`（可信事件）+ `eventLoop` 推进。
> 注：本 skill **不涉及** Akamai 类真实鼠标轨迹/行为采集式的构造边界（用户明确排除）。

### 原则 5 原始 JS 零修改

一律加载**原始、未格式化**的目标 JS，一个字节都不改（目标常带自校验：toString 比对、控制流校验和、文件 hash，改动即触发惩罚分支）。要 hook 靠**目标之外新增**：包 prototype 方法、`defineProperty` 装 getter、沙箱外层拦截、`ctx.expose` 截产物。格式化版只供人眼阅读。对应 `references/iv8-api-contract.md` §3 的"改 JS 插 console → 外部 hook"。

## 3. 验收 = 逐字符对账 + 两道闸

取真值是**手段不是验收**（可能某值抄对了、却漏了另一个目标也读的字段）。最终判据永远是：
1. **两道闸都过**：① 目标 JS 跑完 ② 产物真产出（不是"无错跑完"就算成功）。
2. **本地产物与真机逐字符等价**（`scripts/parity_check.py`）。
3. **但真相在服务器**：200/code=0 才算翻，本地自洽不算（见 `references/part2-discovery.md` §4 分支）。

会变的熵源（计数器、时间、随机数）不照搬瞬时快照，要冻结/对齐。

---

## 4. iv8 原生补丁契约

目标 JS 的运行底座只能是 iv8。不要加载通用浏览器 mock 框架，也不要手写整套 window/DOM。确认 stub 空壳后，按以下契约在目标外部写一个最小补丁：

1. 先用报错栈证明 iv8 的现有实现阻断了目标路径，再用真实 Chrome 核对该 API 的值、形态和必要行为。
2. 补丁通过 `stub_setup_js` 在原始目标 JS 之前注入；不得修改、格式化或重写原始目标文件。
3. 只实现 Trace 已触达的属性和方法；保持函数名、构造方式、原型层级、descriptor、`typeof` 和合法的 `undefined` 与真机一致。
4. 函数和构造器使用 `__iv8__.wrapNative(fn, name)`；不要全局改写 `Function.prototype.toString`。
5. 异步替身使用 iv8 Timer，并在收割产物前调用 `__iv8__.eventLoop.advance/drain`。
6. 补丁前后分别运行相同输入；只有原报错消失、反射表面一致且目标输出对账不引入新分叉，才能保留补丁。

WASM 不使用跨目标通用桥接模板：保留目标自带的 glue 和真实 WASM 字节，只针对 iv8 中被动态证据证明不一致的宿主 binding 做最小修正。Canvas、Audio、字体等真实渲染物理量由浏览器采集并作为声明的环境输入注回 iv8，不能把浏览器产出的最终 token 当成 iv8 执行结果。
